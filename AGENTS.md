# Culturando Agent Orchestration

- At the beginning of every OpenCode session or task for this repository, load the `thesis-latex-maintainer` skill unless it has already been loaded in the current session.
- All repository work must include a thesis-impact evaluation before the task is considered complete.
- Modify the thesis only when the repository change has academic relevance or when direct thesis maintenance requires it.
- Direct work under `thesis/thesis_latex/**` must follow `thesis-latex-maintainer`.
- Commit preparation and commit messages must follow `git-commits`.
- Push preparation must follow `pre-push-sync-knowledge`.
- Before any push, evaluate both project-knowledge synchronization and thesis synchronization.
