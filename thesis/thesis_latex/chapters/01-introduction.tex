% --------------------------------------------------
%
% Obiettivo:
% restringere il problema generale al caso affrontato
% dalla tesi.
%
% Contenuti:
% - molti patrimoni librari privati non sono
%   individuabili dall'esterno;
% - differenza tra possesso, scoperta e accesso;
% - difficoltà per un utente di sapere se un determinato
%   volume è disponibile presso un altro privato.

% --------------------------------------------------
%
% Obiettivo:

%
% Contenuti:
% - catalogazione digitale;
% - indicizzazione;

% - collegamento tra utenti;
% - discovery;
% - possibile condivisione.
%
% Introdurre gradualmente Culturando, senza descriverne
% ancora architettura o tecnologie.

% --------------------------------------------------
%

%
% Contenuti:
% - i libri sono beni fisici;
% - la distanza tra proprietario e utente interessato

% --------------------------------------------------
